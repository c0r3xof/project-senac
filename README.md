Extraia o ficheiro .zip para a pasta do seu servidor local (ex: htdocs/reviva).

Abra o phpMyAdmin e crie uma nova base de dados chamada reviva.

Importe o ficheiro reviva.sql para criar todas as tabelas.

Coloque a imagem do seu logótipo na pasta img/logo-horizontal.png.

Aceda a http://localhost/reviva no navegador.
